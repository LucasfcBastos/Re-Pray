# INSTALAÇÃO

## Mobi-Web-Form

cd frontend/

cd mobi-web-form/

npm install react-router-dom

npm run dev

## Desk-App-Dash

cd frontend/

cd desk-app-dash/

npm install react-router-dom electron concurrently

npm run dev

## Instalações


| Camada | Utilizado | Instalador | Descrição |
| :--- | :--- | :--- | :--- |
| *Frontend* | **React** | `react-router-dom` | Gerenciamento de rotas e navegação |
| | **Electron** | `electron` | Framework para criação de aplicativos desktop |
| | **Utilitários** | `concurrently` | Executa vários comandos simultaneamente |
| | **Utilitários** | `wait-on` | Aguarda a inicialização de serviços/portas antes de rodar outro comando |
| | **Build** | `electron-builder` | Empacota e gera o aplicativo executável final |
